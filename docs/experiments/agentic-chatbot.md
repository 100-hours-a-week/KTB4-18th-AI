# 대화형 검색 워크플로우 실험

브랜치: `experiment/agentic-chatbot`. 기준: `dev` 8157729.

## 실행

```sh
bash run-agentic.sh
```

`http://127.0.0.1:8002/app/`에서 실행한다. 스크립트는 `AGENTIC_CHAT=1`,
`LOCAL_INSPECTOR=1`, `SEARCH_EMBEDDING=v4`를 적용하며 원격 추적을 끈다.
실제 모델 요청에는 비용이 발생한다. 서버 배포에는 이 로컬 스크립트를 사용하지 않는다.

## 현재 동작

- 분류 → 임베딩 → 검색 또는 분류 → 조회 → 제목 보정 → 종료.
- 제목과 가수가 모두 있고 조회에 실패한 경우에만 카탈로그 편집 거리로 오타를 보정한다.
  가수 오타, 한글 제목과 번역 제목의 일반적인 매핑은 보장하지 않는다.
- 정보가 부족하거나 결과가 없으면 요청당 한 번 질문한다. 이어지는 답변에서 검색 문장과
  장르·연도 조건을 보존하며 사용자가 명시적으로 해제한 조건만 해제한다.
- 검색 결과를 본 뒤 LLM이 재시도를 고르는 루프는 제거했다. 결과 내용에 따라 모델이
  도구를 자율 선택하는 범용 에이전트가 아니라 분류 LLM과 코드 정책의 대화형 검색이다.
- 같은 텍스트 대화의 그래프 실행을 프로세스 안에서 직렬화한다. 답변 스트림 전체,
  사진·텍스트 동시 요청이나 다중 워커 사이까지 잠그는 것은 아니다.
- 답변 시작 전 예산은 30초다. 시작된 스트림 전체의 완료 시간을 보장하지 않는다.
- 사진은 비동기 임베딩·DB 검색을 사용해 취소·타임아웃 시 자원을 정리한다.
  STT 경로는 유지한다.

## 연동과 검증

텍스트의 상세 진행 이벤트는 `LOCAL_INSPECTOR=1`일 때만 보낸다.
사진의 추가 진행 단계는 현재 BE의 엄격한 파서와 호환되지 않는다.
배포 전 [BE 연동 수정안](agentic-be-integration.md)을 적용하고 통합 검증해야 한다.

자동 테스트는 실제 모델과 DB 품질 평가를 대체하지 않는다.

검증 입력:

1. `NELL의 The Day Bfore 찾아줘`
2. `공원에 왔어` → `벤치에 앉아 있어`
3. `2010년대 재즈 추천해줘` → `더 잔잔하게` → `연도는 상관없어`
4. `1800년부터 1809년 사이에 발매된 재즈만 추천해줘` → `연도는 상관없어`
