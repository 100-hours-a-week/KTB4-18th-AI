## 1. [뒤로가기] 이전 화면 이동
- 선택 시 기존 채팅 세션의 챗봇 대화 화면 CHAT-001로 이동한다.
- CHAT-001의 기존 대화 내역과 작성 중인 메시지는 유지한다.
- 촬영한 사진과 임시 분석 데이터는 등록하지 않고 폐기한다.
- 사진 촬영, 사진 확인 또는 등록 요청이 진행 중이면 해당 작업을 종료한 후 이동한다.
- 화면 이동 이후 도착한 응답은 화면에 반영하지 않는다.
- 연속 선택으로 중복 이동이 발생하지 않도록 첫 선택 이후 버튼을 비활성화한다.
- CHAT-002에 재진입하면 사진이 촬영되지 않은 초기 상태로 시작한다.

## 2. [사진 미리보기] 촬영 전·후 사진 상태 표시
- 촬영 전에는 기본 안내 이미지와 함께 눈앞의 풍경을 담아주세요, 이 순간에 어울리는 음악을 찾아드릴게요.를 표시한다.
- 촬영이 완료되면 기본 안내 이미지 대신 촬영한 사진을 표시한다.
- 촬영 후 안내 문구를 촬영한 풍경을 확인해 주세요, 추천에 사용할 사진이 선명하게 담겼는지 확인해 주세요.로 변경한다.
- 사진은 원본 비율을 유지하면서 미리보기 영역을 채우도록 표시하고, 영역을 벗어난 부분은 잘라서 보여준다.
- 사진의 회전 정보를 반영하여 올바른 방향으로 표시한다.
- 사진을 불러오는 동안 로딩 상태를 표시한다.
- 사진을 불러오지 못하면 사진을 불러오지 못했어요. 다시 촬영해 주세요.를 표시하고 촬영 전 상태로 되돌린다.
- 한 번에 한 장의 사진만 유지하며, 재촬영을 완료하면 기존 사진을 새 사진으로 대체한다.
- 하단에 사진은 풍경 분석과 음악 추천을 위해서만 사용됩니다.를 표시한다.

## 3. [카메라로 촬영·다시 촬영] 사진 촬영
- 촬영 전에는 버튼명을 카메라로 촬영으로 표시한다.
- 촬영한 사진이 있으면 버튼명을 다시 촬영으로 변경한다.
- 버튼을 선택한 시점에만 카메라 권한을 요청하며, 화면 진입과 동시에 요청하지 않는다.
- 권한이 허용되면 카메라를 실행한다.
- 권한이 거부되면 사진을 촬영하려면 브라우저 설정에서 카메라 권한을 허용해 주세요.와 권한 변경 방법을 안내한다.
- 브라우저 또는 기기에서 카메라 촬영을 지원하지 않으면 버튼을 비활성화하고 기능을 사용할 수 없음을 안내한다.
- 촬영을 완료하면 사진을 미리보기 영역에 표시하고 이 사진으로 추천받기 버튼을 활성화한다.
- 최초 촬영을 취소하면 촬영 전 상태를 유지하고, 재촬영을 취소하면 기존 사진을 유지한다.
- 촬영 중 오류가 발생하면 “사진을 촬영하지 못했어요. 다시 시도해 주세요.”를 표시한다.
- 촬영한 사진은 서비스의 임시 저장 영역에 보관하며, 서비스가 기기 갤러리에 별도로 저장하지 않는다.
- 사진 확인 또는 등록 요청이 진행 중인 동안에는 촬영 버튼을 비활성화한다.

## 4. [이 사진으로 추천받기] 사진 확인 및 추천 요청
- 촬영된 사진이 없으면 버튼을 비활성화한다.
- 다음 조건을 모두 만족할 때 버튼을 활성화한다.
  - 촬영된 사진이 있음
  - 진행 중인 사진 확인 또는 등록 요청이 없음
  - 네트워크 연결 상태가 정상임
- 선택 시 사진이 정상적으로 처리 가능한지와 추천에 필요한 풍경 특징을 충분히 추출할 수 있는지를 확인한다.
  - 사진의 형식, 용량 및 해상도는 서버의 이미지 처리 정책에 따라 검사한다.
  - 사진의 짧은 변이 480px 미만이거나 긴 변이 640px 미만이면 추천에 사용할 수 없는 사진으로 처리한다.
  - 사진이 지나치게 흔들리거나 어둡고, 모델이 풍경·조명·날씨·시간대 등의 특징을 충분히 파악하지 못하면 추천에 사용할 수 없는 사진으로 처리한다.
  - 추천에 사용할 수 없는 사진이면 챗봇 화면으로 이동하지 않고 재촬영 안내 바텀시트를 표시한다.
- 처리 중에는 사진을 확인하고 있어요…를 표시하고 촬영 및 추천받기 버튼을 비활성화한다.
- 추천에 사용할 수 있는 사진이면 기존 채팅 세션의 CHAT-001로 이동한다.
- 이동 후 해당 사진을 사용자 메시지로 표시하고, 사진에서 파악한 풍경 정보를 기준으로 음악 추천을 시작한다.
- 추천에 활용하기 어려운 사진이면 화면을 이동하지 않고 재촬영 안내 바텀시트를 표시한다.
- 사진 확인 및 등록 단계의 제한시간은 30초로 한다. 이후 음악 추천 응답에는 CHAT-001의 응답 제한시간을 적용한다.
- 네트워크 또는 서버 오류가 발생하면 사진을 유지하고 사진을 확인하지 못했어요. 다시 시도해 주세요.를 표시한 뒤 버튼을 다시 활성화한다.
- 임시 사진은 다음 기준으로 처리한다.
  - 추천이 완료되면 서버에 전송된 원본 사진은 풍경 특징 추출 후 삭제하고, 채팅 화면에는 현재 세션 동안 미리보기만 표시한다.
  - 사용자가 뒤로가기 또는 화면 이탈을 선택하면 임시 사진과 채팅 화면의 미리보기를 삭제하고, 진행 중인 요청은 취소한다.
  - 네트워크 오류, 서버 오류 또는 시간 초과가 발생하면 서버에 전송된 임시 사진은 삭제한다. 단, 사용자가 재시도할 수 있도록 현재 화면의 사진은 유지한다.
- 연속 선택으로 동일한 요청이 중복 실행되지 않도록 처리한다.
- 서버는 사진의 형식, 용량 및 필수값을 다시 검사하고 허용되지 않는 요청을 거절한다.

## 5. [재촬영 안내] 추천에 사용하기 어려운 사진 안내
- 사진에서 추천에 필요한 풍경의 특징을 충분히 파악하지 못하면 재촬영 안내 바텀시트를 표시한다.
- 바텀시트가 표시되면 배경 화면을 어둡게 처리하고 배경 화면의 동작을 제한한다.
- 다음 안내 문구를 표시한다.
  - 제목: 사진을 다시 찍어 주세요
  - 설명: 풍경의 특징을 충분히 확인하기 어려워요. 밝은 곳에서 주변이 잘 보이도록 촬영해 주세요.
- 다시 촬영을 선택하면 바텀시트를 닫고 카메라를 실행한다.
- 재촬영을 완료하면 기존 사진을 새 사진으로 교체한다.
- 재촬영을 취소하거나 실패하면 기존 사진을 유지한 채 사진 확인 화면으로 돌아온다.
- 닫기 버튼을 선택하면 바텀시트를 닫고 기존 사진이 표시된 화면에 머무른다.
- 네트워크 및 서버 오류에는 재촬영 안내를 표시하지 않고 별도의 오류 메시지를 제공한다.
